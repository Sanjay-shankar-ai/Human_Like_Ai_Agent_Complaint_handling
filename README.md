# 🤖 Conversational Financial Complaint Agent

An intelligent support assistant that listens, understands, and processes customer complaints in a human-like and empathetic manner. This agent streamlines complaint classification, generates tickets, and sends formal summaries to the bank—all while enhancing customer satisfaction.

---

## Website
https://human-like-agent.streamlit.app/

## ✅ Key Features

- 🧠 Conversational agent that listens and understands customer issues  
- 🗂️ Smart classification of complaints (technical, transaction, card issues, etc.)  
- 📝 Automatically generates formal complaint summaries  
- 📩 Sends complaint summaries to bank support via email  
- 🔄 Tracks and updates customer in real-time  
- 💬 Empathetic communication style to build customer trust  
- 🔁 Ensures routing to the right department  
- ⏱️ Reduces response time and improves service experience  
- 😊 Human-like engagement to improve satisfaction  

---

## 🧠 Tech Stack

- **Frontend**: [Streamlit](https://streamlit.io/)  
- **LLM**: [LLaMA 3.3-70B via Groq](https://groq.com/)  
- **Prompting**: [LangChain PromptTemplate](https://python.langchain.com/docs/modules/model_io/prompts/)  
- **Email**: Python `smtplib` and `email.mime`  
- **Env Management**: [python-dotenv](https://pypi.org/project/python-dotenv/)
